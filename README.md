# Obstacle-avoiding-robot
<img width="108" height="108" alt="image" src="https://github.com/user-attachments/assets/e23cdca3-b740-47db-baa0-c115d8d2f125" />


The goal of this project is to build and develop a robot carusing arduino, That is able avoid obstacles and detect edges in its path. Ther are many real-life applications of this robot including autonomously guided vehicles e.g vacume cleaners .In this repository, the whole code used to achieve the goal, the circuit diagrams and the ouput of the robot will be provided.
About the hardware:
- An Arduino Uno has been used as a microcontroller to feed the software into the components.
- An L293 Motor Driver is used to manage the cables of the motors(wheels).
- 2 infrared sensors are used to detect any obstacles by emmiting infrared light and sensing reflections to determine if an object is in its path. This llows to robot to alter direction based on signals

Note:
If you wish to implement the code in this repository, then you may have to tune the IR sensors and change alter the pins for the directional output of the robot.

Requirement for Obstacle Avoidance and edge detection :

 x1 Arduino Uno
 x2 Infrared Sensor (x3 for more accurate signals of edges/objects in the robot's path)
 x1 9V Battery 
 x1 9V Battery Clip
 x1 Motor Driver DC L293
 x1 Chassis arm for IR sensor to face downwards
 x1 Mini Breadboard
 ~10-12 male-female jumper wires
 ~8-10 male-female jumper wires
 x1 Chassis (or DIY)
 x2 Motor DC motor 12V
 x2 Wheel
